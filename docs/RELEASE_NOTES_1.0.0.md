# Token Ball 1.0.0

**把每一次对话的 Token、花费和余额，放在手边。**

Token Ball 是给 DeepSeek Harness 的悬浮球插件。它常驻在界面右下角，显示当前对话的 Token 用量、按官方峰谷价估算的人民币花费，以及你的充值余额和赠金余额。

## 这一版有什么

- 当前会话 Token：输入、输出、缓存命中、缓存写入、请求数
- 按 DeepSeek 官方价目估算 CNY 花费，区分高峰/空闲时段
- 读取 DeepSeek 账号的充值余额与赠金余额
- 可拖动、点击展开、位置记忆
- 明暗主题、键盘操作、减少动态效果支持
- 本机计算，不上传对话正文或凭据

## 安装

1. 下载本仓库到本机。
2. 在 Harness 的 **Plugins** 页面从本地目录安装，指向仓库根目录。
3. 刷新 Harness 页面，右下角出现悬浮球。

## 一点诚实的说明

- 金额是**估算**，不是平台账单；实际扣费以 DeepSeek 开放平台为准。
- 只统计当前会话；subagent 是独立会话，不计入父会话。
- 余额查询有缓存，和平台账单可能有时间差。
- 法定节假日暂未建模。

## 适合谁

- 每天长时间使用 Harness、想知道“这一轮多少钱”的开发者
- 需要关注 API 预算的小团队
- 正在调试 Agent、优化上下文和缓存命中的构建者
- 用赠金/充值余额、希望随时知道还能用多久的用户
