# Token Ball 1.1.0

**把“上下文还剩多少”也放到手边。**

1.1.0 给悬浮球加上了对 Harness「上下文」面板（`billion-context`）的联动：球体外圈多了一圈上下文压力环，展开卡片可以看到已用 / 上限、实际发送、压缩节省和 Token 构成。

## 这一版新增

- 自动探测可选的 `billion-context` 面板，不需要额外配置
- 球体外圈上下文压力环 + 底部百分比徽标
- 展开卡片新增「上下文」区块：已用 / 上限、发送 Token、压缩节省、压缩块数量
- 系统提示、工具、消息、代码、摘要的 Token 构成条
- 每 10 秒刷新上下文；页面隐藏时暂停，回到前台立即刷新
- 「详情」链接直达对应会话的上下文面板
- 未安装或无法连接上下文插件时，整块 UI 自动隐藏，原有功能不受影响

## 隐私边界

上下文联动只读取聚合数字：占用、发送量、压缩统计和分类占比。会话正文、摘要、工具输出不会进入 Token Ball 的请求链。

## 安装 / 更新

1. 在 Harness 的 **Plugins** 页面从本地目录安装或更新，指向本仓库根目录。
2. 刷新 Harness 页面，右下角悬浮球出现上下文压力环。

> 金额仍是按 DeepSeek 官方价目做的估算，不是平台账单。
